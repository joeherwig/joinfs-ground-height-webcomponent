# Third-party notices

## Ground height data

By default ground heights come from the [Open-Meteo elevation API](https://open-meteo.com/en/docs/elevation-api), which
serves the Copernicus DEM GLO-90 terrain model (Copernicus Programme / European Union and ESA). Open-Meteo's free API is
for non-commercial use and asks for attribution: *Weather data by Open-Meteo.com*. An application that shows these heights to
its users should name the source.
